A collection of C++ and OpenGL projects demonstrating 3D modeling, textures, lighting, camera navigation, and computational graphics techniques.


# CS-330: Computational Graphics and Visualization

## How do I approach designing software?

Throughout this course, I learned how important it is to plan a design before beginning development. For my final project, I created a 3D tabletop scene featuring a coffee mug, book, orange, and vase. I started by identifying the basic geometric shapes needed to construct each object and determining how they would be positioned within the scene. This project helped me develop a better understanding of 3D modeling, textures, lighting, and spatial organization. In future projects, I can apply these skills by breaking larger designs into smaller, manageable components.

## How do I approach developing programs?

My approach to programming involves making changes gradually, testing them, and adjusting anything that does not work as expected. Throughout the milestones, I worked with C++ and OpenGL to create objects, apply textures, configure lighting, and implement camera movement. One challenge I encountered was getting textures to display correctly. Troubleshooting these issues taught me the importance of checking file paths, reviewing code, and testing changes individually. As I progressed through the course, I became more familiar with organizing code into functions and understanding how different components work together to produce a complete scene.

## How can computer science help me in reaching my goals?

Computer science provides me with opportunities to develop skills that I can use throughout my education and future career. As someone pursuing software engineering, I want to continue strengthening my programming and problem-solving abilities. This course introduced me to computational graphics and helped me understand how mathematical concepts, programming, and visual design work together. I am also interested in game development, so learning about 3D environments, lighting, textures, and camera controls gives me a foundation for exploring game engines and creating interactive projects in the future.
